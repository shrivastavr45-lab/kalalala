# Visual design update

The dashboard now uses a forest-green, sea-glass, and warm mineral palette. Selected high-level surfaces use restrained glassmorphism: translucent fills, fine light borders, background blur, and soft shadows. The navigation remains opaque for contrast, while the main analysis cards, control panel, top bar, tabs, chart tooltips, and legal content use the frosted treatment.

The update intentionally avoids purple tones, decorative gradients, external stock imagery, and oversized rounded controls. Focus-visible outlines remain explicit, reduced-motion preferences are respected, and a reduced-transparency media query restores opaque surfaces for users who request reduced transparency.

No application behavior, dataset scope, forecast-selection logic, or metric calculations were changed as part of this visual update.
